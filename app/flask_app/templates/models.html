Machine Learning Architecture

The Weather Engine is designed as a hybrid forecasting system combining internally trained machine learning models with external Numerical Weather Prediction (NWP) products. Predictable atmospheric variables are learned from historical observations while chaotic and physics-dominated variables are delegated to state-of-the-art NWP forecasts. This design minimizes recursive error propagation while maintaining physical consistency across the complete atmospheric state.

Engineering Philosophy


Unlike conventional forecasting systems that attempt to model every atmospheric variable using machine learning, the Weather Engine follows a selective modelling strategy. Variables exhibiting strong deterministic behaviour are predicted using supervised machine learning, whereas variables dominated by large-scale atmospheric dynamics are sourced from external Numerical Weather Prediction (NWP) models.


This hybrid design was developed after extensive experimentation across multiple regression and classification algorithms. The final architecture minimizes recursive forecasting errors, improves long-term stability, and leverages the complementary strengths of statistical learning and physics-based numerical simulation.

Hybrid Weather Engine Architecture

The complete forecasting engine follows a directed acyclic graph (DAG) where atmospheric variables are predicted in dependency order. Stable variables are estimated using machine learning while highly chaotic variables are supplied by Numerical Weather Prediction (NWP).

🌬 Wind Prediction

Shifted to External NWP
Final Validation R² ≈ 0.65

Extensive experimentation was performed using LightGBM, CatBoost and ensemble models with geographical, temporal, radiation, temperature, pressure, moisture and lag-based features. Despite comprehensive feature engineering, validation performance consistently plateaued around an R² of 0.65 while training performance exceeded 0.85, indicating strong overfitting and an inherent predictability ceiling.

Project Conclusions

  • Wind depends on regional pressure gradients rather than purely local weather.
  • Synoptic-scale systems influence local wind several hundred kilometres away.
  • Terrain roughness, valleys and channeling dominate local flow.
  • Numerical Weather Prediction solves these physical processes directly.

Rain Classification & Rain Amount

Precipitation forecasting is separated into two independent tasks. The occurrence of rainfall is treated as a binary classification problem, whereas rainfall amount is supplied through Numerical Weather Prediction due to the complexity of quantitative precipitation forecasting.

🌧 Rain Classification

Binary Classification

Objective

Predict whether rainfall will occur during the forecast period while simultaneously estimating prediction confidence.

Decision Threshold

Probability Threshold = 0.30 (Recall Optimised)

Why Optimise Recall?

Missing an actual rainfall event (False Negative) is considered substantially more expensive than incorrectly predicting rain. Therefore, the decision threshold was intentionally reduced from the conventional 0.50 to 0.30 to maximise rainfall detection.

🌦 Rain Amount

External NWP
ML Regression Replaced by Physics-Based Forecasting

Rainfall quantity prediction was initially investigated using Tweedie regression. While acceptable performance was obtained for typical rainfall events, the model consistently underestimated extreme precipitation and suffered from zero-inflated target distributions.

Project Decision

  • Rare extreme rainfall events are underrepresented within historical training data.
  • Quantitative precipitation depends upon complex three-dimensional atmospheric physics.
  • Numerical Weather Prediction models directly simulate cloud microphysics.
  • Using the same NWP provider for wind, cloud and rainfall maintains physical consistency.
  • External NWP remains considerably more reliable beyond short forecasting horizons.

Cloud Cover & Weather Code Prediction

Cloud cover and weather code prediction illustrate the hybrid forecasting philosophy adopted throughout the Weather Engine. Cloud cover is delegated to Numerical Weather Prediction while the final weather condition is inferred using a supervised multi-class classification model.

☁ Cloud Cover

External NWP
Internal ML Replaced by External Numerical Weather Prediction

Cloud forecasting was intentionally removed from the machine learning pipeline after extensive evaluation. Unlike temperature or pressure, cloud formation depends upon three-dimensional atmospheric dynamics and satellite-observed processes that cannot be adequately represented using historical tabular weather observations alone.

Project Decision

  • Eliminates recursive error accumulation across multiple forecast horizons.
  • Enables detection of approaching weather systems beyond the local region.
  • Captures high-altitude cloud structures invisible to surface observations.
  • Removes dependency upon lag-based cloud features during production.

Hybrid Consensus Filter


The Weather Code model is intentionally not used as the sole source of truth. Instead, every prediction undergoes a consensus verification stage with the external Numerical Weather Prediction system.

Predictions exhibiting strong agreement with Numerical Weather Prediction are accepted directly. When disagreement occurs on historically weak weather classes, the engine defaults to the physics-based NWP forecast to preserve physical realism and improve operational robustness.

Final Hybrid Forecasting Strategy

The final Weather Engine architecture was developed after extensive experimentation across regression, classification and ensemble learning techniques. Rather than maximising the number of machine learning models, the objective was to maximise overall forecasting reliability through an evidence-based hybrid strategy.

Project Outcome


The resulting Weather Engine is neither a purely machine learning system nor a conventional Numerical Weather Prediction pipeline. Instead, it combines the strengths of both paradigms into a hybrid architecture where statistical learning captures local temporal relationships while physics-based forecasting provides global atmospheric consistency.


This approach reduces recursive forecasting errors, improves robustness for long forecast horizons and allows each atmospheric variable to be predicted using the methodology best suited to its underlying physical behaviour. The resulting engine therefore balances predictive accuracy, computational efficiency and operational reliability.
