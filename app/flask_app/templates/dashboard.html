Dashboard Information

This dashboard evaluates the forecasting performance of the Weather Engine using historical prediction and evaluation records stored in the database.

Trend visualisations display the latest fifteen available forecast dates (or fewer if less historical data is available). Forecast vs Actual graphs compare model predictions against recorded weather observations averaged across all evaluated cities.

City Performance summarises the long-term forecasting accuracy for each monitored city based on every evaluated forecast currently stored in the system.
